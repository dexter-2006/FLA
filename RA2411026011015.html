Why this grammar works

Explain the rule, not just the answer.

1
Start with S

S is the start symbol; it is the variable we keep replacing.

2
Apply S → aSb

Every use adds one a on the left and one b on the right.

3
Apply S → ε

Epsilon removes S and ends the derivation.

4
Result

Equal counts, and all a's come before b's.

Example: S ⇒ aSb ⇒ aaSbb ⇒ aabb.
The big idea

Same language, different lens

A PDA recognizes strings using a stack. A CFG generates strings using production rules.

01 / PDA = checker

Reads an input that already exists.

read symbol → inspect stack → push/pop → accept/reject

Think: “Does this string follow the rule?”

02 / CFG = generator

Builds a string from a start symbol.

S → aSb → aaSbb → aabb

Think: “How can I create a valid string?”
